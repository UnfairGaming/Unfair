# Unfair

This project is built with Gradle, targeting Java 25.

## Build

Windows:

```powershell
.gradlew.bat clean build
```

Linux/macOS:

```bash
./gradlew clean build
```

The build output is in `build/libs/`.

## Run

```powershell
.gradlew.bat run
```
