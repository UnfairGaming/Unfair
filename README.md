# Unfair

本项目使用 Gradle 构建，编译基线为 Java 25。

## 构建

Windows:

```powershell
.\gradlew.bat clean build
```

Linux/macOS:

```bash
./gradlew clean build
```

构建产物位于 `build/libs/`。

## 运行

```powershell
.\gradlew.bat run
```
