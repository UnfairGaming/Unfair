# Unfair-MCP 开发须知

## 基本约束

1. 使用 JDK 25 和项目现有的 Java 25 配置。
2. 使用 UTF-8。
3. 修改前先阅读相关类、调用方和版本判断。不要只复制另一个项目的片段。
4. 优先复用现有工具类和 Via 状态追踪；确实没有等价逻辑时，才在对应包中增加最小实现。
5. 不要为了小改动拆出大量方法，也不要顺手重构无关代码。
6. 除非用户明确要求，不要执行 Gradle 编译 / 构建等任何任务。只有用户要求时再运行针对性的检查或构建。
7. 不写解释性废话注释。只在版本差异、边界条件或非直观公式前留下简短注释。
8. 除非用户明确要求或需要使用 Git 来回滚/回退，不要使用任何Git指令。
9. Min / Max 属性要 Override verifyValue() 方法，使 Min 不能大于 Max，Max 不能小于 Min,可以参考 AutoClicker 148 - 159 行的实现。
